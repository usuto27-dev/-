# 体脂肪8%チャレンジ

年末までに体脂肪8%を目指すための、食事・筋トレ・体組成の管理アプリです。
ビルド不要・サーバー不要で、ブラウザだけで動作します（データはブラウザの localStorage に保存されます）。

## 使い方

1. `index.html` をブラウザで開く（もしくは任意の静的サーバーで配信する）
2. 「設定」タブでプロフィール（身長・生年月日・活動レベル・目標体脂肪率・目標日）を入力
3. 「体組成」タブで体重・体脂肪率を記録
4. 「食事」タブで食事内容とカロリー・PFCを記録
5. 「筋トレ」タブでトレーニング内容を記録
6. 「ダッシュボード」で目標までの日数、目標カロリー・たんぱく質、進捗を確認

## 機能

- ダッシュボード: 目標達成までの日数、現在の体脂肪率・体重・除脂肪体重(LBM)、目標摂取カロリー/たんぱく質、本日の摂取状況、体脂肪率の進捗バー、体重・体脂肪率の推移グラフ、直近7日間のカロリー収支グラフ
- 体組成記録: 日々の体重・体脂肪率を記録し、除脂肪体重を自動計算
- 食事記録: 食事区分ごとにカロリー・たんぱく質・炭水化物・脂質を記録し、日別合計を表示
- 筋トレ記録: 種目・重量・回数・セット数を記録し、種目別の総ボリューム推移をグラフ化
- 設定: Mifflin-St Jeor式によるTDEE計算、カロリー赤字設定、目標体脂肪率・目標日の設定
- データのJSONエクスポート/インポート、全データ削除

## 計算式

- BMR（基礎代謝）: Mifflin-St Jeor式
- TDEE: BMR × 活動レベル係数
- 目標摂取カロリー: TDEE − カロリー赤字（設定で調整可能）
- 除脂肪体重(LBM): 体重 ×（1 − 体脂肪率）
- 目標たんぱく質: 除脂肪体重 × 2.2g（減量期に筋肉量を維持するための目安）

## データについて

すべてのデータはブラウザの localStorage に保存されます。別端末・別ブラウザとは共有されないため、
「設定」タブの「JSONエクスポート」で定期的にバックアップを取ることをおすすめします。
